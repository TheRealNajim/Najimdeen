# Najimdeen Ajadi — Portfolio

[Live site](https://www.najimdeenajadi.xyz/) · [Résumé (PDF)](Najimdeen_CV.pdf)

A static portfolio for my frontend work, cybersecurity studies, and ICT experience. It uses HTML, CSS, and a small JavaScript file without a build step.

## Run locally

```sh
python -m http.server 3000
```

Open <http://localhost:3000/>. The project demos are linked, not embedded. The contact form opens an email draft; it does not submit to a server.

The homepage is in `index.html`. Keep the corresponding standalone page in sync when editing a section, and bump the CSS or JavaScript URL version when changing an immutable asset.
